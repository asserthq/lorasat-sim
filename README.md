# Подготовка
**Пакетный менеджер**
Управление зависимостями с помощью современного пакетного менеджера `uv` 
Настраивает зависимости и создает виртуальное окружение. Предоставляет удобные алиасы для управления и запуска из виртуального окружения (python venv).
Установка: https://docs.astral.sh/uv/getting-started/installation/

# Начало работы
Запуск командой `uv run <имя скрипта>`
